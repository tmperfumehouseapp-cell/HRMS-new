Step-by-step: first-time setup (read once)
  1. Spare number. It must NOT be active in the WhatsApp or WhatsApp Business phone app (delete the account in the app first, or use a fresh SIM). It must be able to receive one SMS/call for the code.
  2. developers.facebook.com → My Apps → Create App → type Business → connect your verified Business Portfolio → add the product WhatsApp.
  3. WhatsApp → API Setup → “Add phone number” → enter the spare number and verify with the code. Note the Phone number ID and WhatsApp Business Account ID shown there.
  4. Permanent token: business.facebook.com → Settings → Users → System users → Add (Admin) → Assign assets: your app + WhatsApp account (full control) → Generate token with whatsapp_business_messaging and whatsapp_business_management → “Never expire”.
  5. App secret: your app → Settings → Basic → App secret → Show.
  6. Put the five values in config.php on Hostinger (lines below). Never send them to anyone in chat.
  7. Back here: do step 2 (webhook), press Connect webhook for this account, then Check now.
  8. Send “hi” from your own phone to the new number. It should appear in My Chats → Waiting within seconds. Transfer it to a salesperson and reply.
Lines to add to config.php (before the closing line, if any):
define('WA_TOKEN',        'paste-system-user-token');
define('WA_PHONE_ID',     'paste-phone-number-id');
define('WA_WABA_ID',      'paste-whatsapp-business-account-id');
define('WA_APP_SECRET',   'paste-app-secret');
define('WA_VERIFY_TOKEN', 'any-long-random-text-you-choose');
Until you switch the number over, AiSensy keeps working on its own number. A number can live on only one provider at a time — move your main number only at cut-over.
