Manual order

For a customer who is not in HRMS (came from outside). Type the customer's number, then fill the same Manual order sheet as in a chat (payment, perfumes, combo). It becomes a normal order and counts for you like a Shopify order.

Regular and AiSensy: pick the perfumes, payment and address (AiSensy is the same order, only tagged AiSensy). Myntra / Amazon / Flipkart: the customer already ordered there, so you only attach the screenshot.

Marketplace order

It is counted for you at once. The same marketplace order number cannot be added twice. Admin and the Sales Head can see the screenshot, remove the order or give it to someone else.

Enter the customer's number, name and address inside the sheet, choose Query or Campaign, then the payment, perfumes, other products and chain. The order is counted for you and goes to Allocation by itself.
