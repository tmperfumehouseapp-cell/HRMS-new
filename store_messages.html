Store messages

The messages the store sends to its own customers: birthdays to send today, the message wording and photo, and each customer’s gifts

📋 How the store messages work

🎂 Birthday gift — the day before a customer’s birthday the code is made and the customer appears in To send today below with the message already written. Tap 💬 Open WhatsApp, send it, then tap ✔ Done: it leaves the list, so everyone can see it was sent. 📷 Copy photo puts the photo on your clipboard to paste into the chat.
🎁 Gifts — a customer with a review gift or a birthday code: type the phone number or code in Check a customer’s gifts, give the free perfume and tap Mark used.
After every bill — Store → Billing shows Send on WhatsApp: WhatsApp Web opens in a window beside the page with the order thank-you below already written (bill link, community and review links). Birthdays open in the same window, from the same WhatsApp number. Links are set in Customer follow-up, managers only.
