Target rules

Each rule sets the daily target on the days it covers. A target set by hand always wins. Days in no rule use the employee's profile / monthly target. A new Sales Executive follows a fixed ladder for the first four weeks instead (₹10,000 / 15,000 / 20,000 / 25,000 a day by week); a target set by hand replaces it — higher or lower.

Day timing

A business day runs from its start time until the next day's start time. Orders on this page are shown in that window — for example 10:00 AM to the next day 10:00 AM. Default is 10:00 AM every day.

The same setting is used on Targets and Attendance.
